# Инфраструктура Yandex Direct

Этот корневой модуль Terraform создаёт новую IPv4 VPC, подсеть, группу безопасности
с ограниченным доступом, зарезервированный публичный IPv4 и ВМ Ubuntu 24.04.
Он не подключается к ВМ и не развёртывает VPN-приложение. Учётные данные Yandex
читаются только через стандартные механизмы аутентификации провайдера.

Группа безопасности открывает Direct на UDP/1194 и вход multi-hop-клиентов
на UDP/1195. Она не открывает транзитный порт AWS UDP/1196. Пересылкой трафика
управляет межсетевой экран хоста, а не Terraform или Docker; он гарантирует,
что клиентский пул multi-hop не имеет резервного выхода через WAN Yandex.

В MVP состояние намеренно хранится локально и содержит конфиденциальные
инфраструктурные данные. Запускайте с `umask 077`, храните состояние и
`terraform.tfvars` на зашифрованном диске, никогда не коммитьте и не публикуйте их.
