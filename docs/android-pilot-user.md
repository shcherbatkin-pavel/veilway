# Установка Veilway для Android

Версия раздачи по публичному манифесту на 2026-10-14 — 0.1.3-pilot.
Публикация 0.1.3-pilot согласована оператором; отложенная ручная приёмка
отражена в [статусе](status.md);
эта инструкция сама по себе не подтверждает обновление рабочего сайта.

Пилотная версия предназначена для Android 10 и новее, ARM64. Используйте
подписанный `veilway-0.1.3-pilot.apk`: откройте в панели «Инструкция → Android»
и нажмите «Скачать Veilway для Android». APK доступен также по прямой ссылке
`https://veilway.ru/downloads/android/veilway-0.1.3-pilot.apk` после выпуска
обновлённой веб-панели. Рядом доступны исходники и контрольные суммы SHA-256.
Оператор должен сначала обновить API и панель: предыдущая версия сервиса
не поддерживает вход из приложения.

1. Установите APK. Если Android попросит, разрешите установку из источника,
   которым открыли этот файл. После установки разрешение можно отключить.
2. Откройте Veilway и нажмите «Войти в Veilway».
3. Нажмите «Открыть вход», войдите через Google в системном браузере,
   сверьте код с приложением и подтвердите вход. Подтверждайте только свой код.
4. Вернитесь в приложение. Выберите назначенный профиль. Если профилей нет,
   попросите администратора назначить доступ вашему аккаунту.
5. Откройте выбор приложений, отметьте YouTube и Telegram, оставьте OZON
   и ВКонтакте без отметки. Нажмите «Сохранить выбор».
6. Нажмите «Подключить» и подтвердите системное разрешение VPN.

Только выбранные приложения используют VPN. Если открыть OZON или YouTube
в браузере, применяется настройка **самого браузера**, а не отдельного сайта.
Список можно менять; новый выбор применяется после отключения и подключения.

При обрыве выбранные приложения ждут восстановления VPN; остальные работают
напрямую. Явное отключение, принудительная остановка Veilway, остановка службы
системой или запуск другого VPN снимают защиту. Эта версия не поддерживает
системный always-on и системную блокировку всех соединений без VPN.

Проверка на телефоне:

- При статусе «Подключён» запустите несколько новых видео YouTube.
- Получите новое сообщение Telegram, а не только откройте сохранённую переписку.
- Откройте каталог OZON и ленту ВКонтакте, сохраняя VPN включённым.
- Повторите на Wi-Fi и мобильной сети, после смены сети и выключения экрана.
- Для проверки различия маршрутов можно временно выбрать только браузер,
  проверить публичный IP, затем снять отметку, переподключиться и повторить.
  Записывать или отправлять IP оператору не требуется.

Сообщите оператору версию Android и приложения, какой шаг прошёл или не
прошёл, тип сети и видимый статус Veilway. Не отправляйте профиль, ключи,
токены, содержимое сообщений или журналы. Работа OZON через прямое подключение
проверяется отдельно: приложение VPN не исправляет сбои самого сервиса.
